<h1>Games Shop Website</h1>
<p>
    This README is also available in <a href="./README.md">English</a>.
</p>
<p>
    Um site fictício de loja de games desenvolvido com <strong>HTML5</strong> e <strong>CSS3</strong>.
    Foi um dos meus primeiros projetos, criado para praticar layouts básicos, formulários e estilização.
    Este projeto é estático e não responsivo.
</p>
<p>
    🔗 Live Demo: <a href="https://games-shop-website-asrdrgm.vercel.app/" target="_blank">Ver na Vercel</a>
</p>
<h2>Sobre</h2>
<p>
    O site simula uma vitrine simples para uma loja de games, incluindo uma seção de apresentação,
    formulário de contato, links para redes sociais e logos de marcas. Ele utiliza layouts com largura fixa
    e não se adapta a dispositivos móveis.
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>Google Fonts (Bungee, Roboto)</li>
    <li>Imagens Estáticas (logos, fachada da loja, ícones de redes sociais)</li>
</ul>
<h2>Funcionalidades</h2>
<ul>
    <li>Menu de navegação com links âncora;</li>
    <li>Imagem da fachada da loja com texto descritivo;</li>
    <li>Logos de marcas (Nintendo, Xbox, PlayStation);</li>
    <li>Formulário de contato com nome, e-mail, telefone e mensagem;</li>
    <li>Links para redes sociais com ícones;</li>
    <li>Rodapé com direitos autorais.</li>
</ul>
<h2>Notas</h2>
<p>
    Este foi um dos meus primeiros projetos. O layout é fixo e não é compatível com dispositivos móveis.
    Ele serve como um marco de aprendizado em HTML semântico e fundamentos de CSS.
</p>
