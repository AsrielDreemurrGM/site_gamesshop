<h1>Games Shop Website</h1>
<p>
    Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
    A fictional game store website built with <strong>HTML5</strong> and <strong>CSS3</strong>.
    It was one of my first projects, created to practice basic layouts, forms, and styling.
    This project is static and not responsive.
</p>
<p>
    🔗 Live Demo: <a href="https://games-shop-website-asrdrgm.vercel.app/" target="_blank">View on Vercel</a>
</p>
<h2>About</h2>
<p>
    The site simulates a simple storefront for a game shop, including a presentation section,
    contact form, social media links, and brand logos. It uses fixed-width layouts and does not
    adapt to mobile devices.
</p>
<h2>Technologies Used</h2>
<ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>Google Fonts (Bungee, Roboto)</li>
    <li>Static Images (logos, store front, social media icons)</li>
</ul>
<h2>Features</h2>
<ul>
    <li>Navigation menu with anchor links;</li>
    <li>Storefront image with description text;</li>
    <li>Brand logos (Nintendo, Xbox, PlayStation);</li>
    <li>Contact form with name, email, phone, and message;</li>
    <li>Social media links with icons;</li>
    <li>Footer with copyright.</li>
</ul>
<h2>Notes</h2>
<p>
    This was one of my first projects. The layout is fixed and not mobile-friendly.
    It serves as a learning milestone for semantic HTML and CSS basics.
</p>
